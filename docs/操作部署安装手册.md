## 二、安装步骤

### 2.1 获取代码

```bash
git clone <仓库地址> xuanshu-plus
cd xuanshu-plus
```

### 2.2 配置 Node 环境（必做）

在仓库根目录创建 `.env.node`，内容为一行：

```
NODE_BIN=D:\Java\nodejs\node-v22.17.0-win-x64\node.exe
```

> 所有脚本（`run.mjs` / `typecheck.mjs`）会读取该路径调用 Node，绕开 PATH 死链接问题。

### 2.3 安装依赖

```bash
node scripts/run.mjs install        # 等价 npm install，走 npmmirror 镜像
```

`package.json` 已声明 npm workspaces，会自动安装 7 个包（core / ledger / intake / answer / ai / knowledge / reader）+ Web 应用的全部依赖（含 `lunar-javascript`、`astronomy-engine`、`iztro`）。

### 2.4 环境体检

```bash
node scripts/run.mjs doctor
```

预期输出 `[doctor] 全部通过`（检查 Node/npm/tsx/vitest/lunar-javascript/iztro/.env.node）。

## 三、运行

### 3.1 开发模式（推荐）


### 3.2 生产构建与本地预览

## 五、部署

### 5.1 Web 端（当前唯一可交付壳）

1. 构建：`node scripts/run.mjs build:web`
2. 产物：`apps/web/dist/`（index.html + assets，纯静态，**无后端依赖**）
3. 托管方式（任选）：
   - **Nginx 示例**：
     ```nginx
     server {
       listen 80;
       server_name xuanshu.example.com;
       root /var/www/xuanshu/dist;
       location / { try_files $uri $uri/ /index.html; }
     }
     ```
   - GitHub Pages / 任意静态托管 / 内网文件服务器均可（SPA 需回退到 index.html）。
4. 离线能力：全部排盘与检索在浏览器本地完成，无服务端、无遥测。

### 5.2 桌面端（Windows，Electron 壳）

**当前状态：已出包。NSIS 安装包 + portable 单文件，含 Key 安全存储与主进程 AI 代理。**

- 技术栈：Electron 44 + `safeStorage`(Windows=DPAPI) 密钥加密 + Win11 Mica 背景 + Snap Layouts（保留原生标题栏）+ 系统主题；NSIS x64 + portable 分发。
- 工程：`apps/desktop`（`main.ts` 主进程 / `preload.ts` 受控桥 / `electron-builder.yml` 打包配置）。
- 构建 & 打包：
  ```bash
  node scripts/run.mjs desktop:build   # 仅编译壳 → apps/desktop/dist
  node scripts/run.mjs desktop:dist    # Web 构建 + 壳编译 + electron-builder 打包
  ```
  产物在 `apps/desktop/release/`：
  - `玄枢-0.1.0-x64.exe`（NSIS 安装，可选手动选择安装目录/桌面快捷方式）
  - `玄枢-portable-0.1.0-x64.exe`（免安装单文件）
  - Web 静态资源经 `extraResources` 置于 `resources/web-dist`，主进程按此加载。
- 开发自测（需先另开 `node scripts/run.mjs dev:web` 供 localhost:5173）：
  ```bash
  npm run desktop:dev        # 以 XUANSHU_DEV=1 启动壳，加载本地开发服务器
  ```
- **密钥链路（区别于 Web 端的内存 Key）**：桌面端 AI Key 经 `keychain.set` 存入主进程，用 `safeStorage.encryptString`（Windows=DPAPI，绑定当前用户）加密后落盘到 `%APPDATA%/玄枢/keys.json`；渲染进程只能读写，**Key 明文不进 localStorage**。AI 对话/测试由主进程 `ai:chat` 代理（Key 只在主进程短留），Web 端逻辑对桌面透明（`preload` 暴露 `window.xuanshuDesktop`，Web 自动检测切换到安全路径）。
- 隐私与安全：`contextIsolation` + `sandbox` + `nodeIntegration:false` + CSP；外部链接经 `setWindowOpenHandler` 一律走系统浏览器。
- 已知注意：当前应用图标为 Electron 默认图标（未挑 .ico 资源），如需替换在 electron-builder.yml 的 `win.icon` 指定图标并重出包。
- 与 Android 一致的内置知识库：首屏后异步载入 **14200 段** 公有领域原典（表见 §5.3）。

### 5.3 移动端（Android 16/17 双轨）

**当前状态：debug APK 已可出包并已在 LDPlayer 14 模拟器验证可用。**

- 工程：`apps/web/android`（Capacitor 8.5.x + targetSdk 36 / minSdk 24 / AGP 8.13 / Gradle 8.14.3，满足 Play 合规）。
- 构建：`node scripts/run.mjs android:build` → 输出 `release/xuanshu-debug.apk`（当前约 5.14 MB，包名 `com.xuanshu.workbench`）。
- 安装到真机/模拟器：
  ```bash
  adb connect 127.0.0.1:5555        # LDPlayer 模拟器默认端口
  adb install -r release\xuanshu-debug.apk
  adb shell am start -n com.xuanshu.workbench/.MainActivity
  ```
- 功能验证（CDP）：`node scripts/verify-android-full.mjs`（四术排盘 + 内置知识库 + AI 面板 + 引用回链）与 `node scripts/verify-android-kb.mjs`（知识库专项：内置书目 + 原文回链）；需先 `adb forward tcp:9222 localabstract:webview_devtools_remote_<pid>`。
- 内置知识库：首屏后异步载入公有领域原典 **14200 段**，断语引用自动回链并内联原文；未命中（如 D 级规则）按引用纪律显示缺口。**IndexedDB 落库**：首启构建 BM25 索引并写入库 `xuanshu-knowledge`（语料 + 索引快照，正文级 `corpusHash` 版本校验）；二次启动命中快照时仅做轻量一致性校验、不重建 BM25；语料更新或快照损坏自动重建。内置书目一览：

  | 书 | 作者/题撰 | 内容规模 | 说明 |
  |---|---|---|---|
  | 《周易》 | 传伏羲/文王/周公/孔子 | 448 段 | 64 卦卦辞 + 384 爻辞 |
  | 《增删卜易》 | 清·野鹤老人 | 3565 段 · 130 卷章 | 六爻断法主典（旬空/月破/应期等规则回链） |
  | 《卜筮正宗》 | 清·王洪绪 | 2076 段 · 60 章 | 用神分类定例/月破论/旬空论/纳甲装卦歌等 |
  | 《黄金策》 | 明·刘基（题） | 3579 段 · 34 章 | 总断千金赋 + 天时/身命/婚姻/求财/家宅/失脱等分类占断 33 章 |
  | 《易冒》 | 清·程良玉 | 3349 段 · 83 章 + 3 序 | 甲子章第一至失物章第八十三，含纳甲/六亲/六神/世应章等 |

- 知识库扩展：`scripts/fetch-diancang.mjs` 拉取公有领域 `source.txt` → `scripts/kb-build.mjs` 切分生成 `corpus.jsonl` 与内置 TS 模块（支持独立标题行 / 内嵌章节标题两种切分模式，句级按「。！？；．」切分）→ 重新构建即可；语料更新后运行 `node scripts/run.mjs verify-citation` 校验引用字段。
- 工程坑位（详见 v5 §17.2）：本机 `jdk21.0.7` 实为 **Oracle GraalVM 21**（jlink 与 AGP 不兼容），Android 构建必须用标准 **Temurin JDK 21**（`D:\Java\jdk\jdk-21.0.12.1+1`）；Gradle 发行包走腾讯镜像、Maven 依赖走阿里云镜像（已写入工程）。
- 前瞻轨：Capacitor 9 + target 37（Android 17）分支规划见 v8 §2.3/§11 P5。

## 六、操作手册（Web 工作台使用）

工作台引导流程与 v8 §0.4 的「6 步向导」一致（支持**四术切换：六爻 / 梅花易数 / 八字 / 紫微斗数**）：

| 步骤 | 操作 | 说明 |
|---|---|---|
| ⓪ 选术数 | 点击顶部「六爻 / 梅花易数 / 八字 / 紫微」Tab | 各术独立排盘输入与断语规则；通用盘面渲染 |
| ① 选事项 | 点击 14 类事项（失物/姻缘/事业/求财/学业/健康/出行/官非/择日/家宅/生育/合作/决策/其他） | 自动加载对应「断事路径卡」：主用术数、怎么问、取用神、读哪本书 |
| ② 问得准 | 输入问句（建议含「谁/什么事/什么时间」） | 实时提示问句质量问题与改进示例；健康/生育/官非等敏感事项给出专业机构指引 |
| ③ 排盘输入 | 六爻/梅花：摇卦/报数/手动/时间卦/字占；八字/紫微：出生年月日时 + 性别 | 各术引擎离线计算，`configHash` 可复现 |
| ④ 盘面 | 通用盘面渲染（爻位表 / 四柱 / 体用 / 十二宫格） | 六爻标世应动空破；八字显四柱十神大运；紫微显十二宫主星 |
| ⑤ 断语 | 每条断语带 `ruleId` + 出处角标 + **原文内联（内置知识库 14200 段自动回链，覆盖 18 部内置典籍）** | 未命中引用显示「请导入书库」（D 级规则按纪律不伪装） |
| ⑥ AI 精解（可选） | 设置面板选厂商/填 Key/模型 → 测试连接 → 精解 | Key 仅存内存；请求按「禁止算盘 + 引用纪律」提示工程；判断卡带证据缺口清单 |
| ⑦ 记录 | 一键存档到案例本（每术 99 条配额，90 条软提醒） | **本地持久化（刷新/重启不丢）**；支持导出（JSON/CSV/Markdown）与导入合并、事后回标校准 |

**使用提示**
- 一事一卦；7 日内同事项重复起卦会提示先看上一条（古籍「初筮告，再三渎」）。
- 珍贵物品疑似被盗时，卦象仅供参考，**请报警并保留证据**。
- 支持离线：断网后排盘、检索、记录全部可用（内置五部原典语料随应用预导入，检索开箱即用；另支持导入自有书库扩充）。

## 八、数据与隐私

- **本地优先**：盘面、案例本、标注全部存储在本地（Web 为 localStorage 持久化案例本 + 内存盘面；桌面端 `%APPDATA%/xuanshu`）。
- **默认不上传**：不云同步、无遥测；AI 精解默认关闭，开启需用户自备 Key（见 v8 §10）。
- **导出**：案例本可导出 `.xuan-case.json` / CSV / Markdown，便于备份与迁移。
- **免责**：应用内常驻免责声明——不构成医疗/投资/法律等确定性预测。

## 九、故障排查

| 现象 | 原因 | 处理 |
|---|---|---|
| `node 不是内部或外部命令` | PATH 中 node 是死链接 | 按 §2.2 配置 `.env.node`，所有命令用 `node scripts/run.mjs ...` |
| `npm install` 超时 | 外网慢 | `.npmrc` 已指向 npmmirror；重试即可 |
| `doctor` 报缺依赖 | 未安装或装到一半 | 重新 `node scripts/run.mjs install` |
| `android:build` 报「无效的源发行版 21」 | 用了 JDK 17 | 改用标准 Temurin JDK 21（`D:\Java\jdk\jdk-21.0.12.1+1`）；勿用 GraalVM 21（jlink 与 AGP 不兼容） |
| `android:build` 报 jlink 执行失败 | JDK 为 GraalVM/无 jmods | 同上，换标准 OpenJDK 21 |
| Gradle 下载/依赖解析失败 | 网络受限 | 已内置腾讯 Gradle 镜像 + 阿里云 Maven 镜像；在线失败自动降级 `--offline`（本地缓存） |
| `dev:web` 端口被占 | 5173 被占用 | 修改 `apps/web/vite.config.ts` 的 `server.port` |
| 节气时间与网上略有出入 | 流派/历元差异 | 本引擎与 lunar-javascript 最大差 0.7 分钟；差异进 `calibration-report` |
| 浏览器打开白屏 | 首次启动 vite 预构建中 | 等待几秒刷新；或确认访问的是 5173 端口 |
| 想改默认事项/问法提示 | 业务规则 | 见 `packages/intake/src/taxonomy.ts`、`playbooks.ts` |
