# 功能矩阵

本页只记录当前代码可以执行和验证的能力。“已实现”不代表传统算法已经完成独立学术校勘；它表示存在可运行入口、结构化输出和相应自动检查。“受限”表示能力存在，但平台、安全或证据边界仍需用户注意。

| 术数 | 状态 | 当前入口与输出 |
|---|---|---|
| 六爻 | 已实现 | 时间/数字/手工起卦，六爻盘、动变、规则证据与日期化应期 |
| 梅花易数 | 已实现 | 时间/数字起卦，体用、生克与规则证据 |
| 小六壬 | 已实现 | 月日时起课，三宫结果与规则证据 |
| 奇门遁甲 | 已实现 | 阴阳遁、局数、九宫盘、关系分析与日期化应期 |
| 大六壬 | 已实现 | 月将、天地盘、四课三传与规则证据 |
| 金口诀 | 已实现 | 地分、将神、贵神、人元、五动与规则证据 |
| 八字 | 已实现 | 四柱、十神、强弱、用神、趋势、合婚与证据分层解读 |
| 紫微斗数 | 已实现 | 命盘、十二宫与主星信息 |

## 工作流与研究能力

| 能力 | 状态 | 说明 |
|---|---|---|
| 事项引导 | 已实现 | 对问句做分类和质量检查，并给出起盘前提示 |
| 路径卡中心 | 已实现 | 12 张路径卡；支持检索、分类、9 步展开、A-E 证据等级、典籍定位和带入工作台 |
| 万年历 | 已实现 | 月历、农历、干支、节气、宜忌、冲煞与单日详情 |
| 命理工具 | 已实现 | 每日运势、称骨、八字合婚、奇门关系分析 |
| 案例中心 | 已实现 | 检索、术数/状态筛选、存档、结果回标、应期统计和三种格式导出 |
| 典籍书阁 | 已实现 | 18 部、387 章、14200 段；书目检索、章节选择、繁简/异体检索、四种文本层、阅读进度和本地批注 |
| 引用回链 | 已实现 | 规则通过 `ruleId`、`segId`、`CitationRef` 和 `charRange` 定位原文；13895 条引用字段通过校验 |
| 第三方 AI 精解 | 受限 | 用户主动配置后才调用；仅解释结构化盘面，AI 输出为 E 级，不作为排盘或原典 |

## 平台能力

| 能力 | Web | Electron | Android |
|---|---|---|---|
| 八术、工具、书阁、案例 | 支持 | 支持 | 支持 |
| AI Key 持久化 | 不支持，仅本页内存 | 支持，系统 `safeStorage` 加密 | 不支持，仅本页内存 |
| 外部 AI/搜索请求 | 浏览器 CORS 允许时可用 | 由受控主进程代理 | WebView 网络条件允许时可用 |
| 原生通知/分享 | 不适用 | 未接入 | 未接入 |
| 案例与阅读状态 | 浏览器本地存储 | Chromium 本地存储 | WebView 本地存储 |

## 明确未完成

- Android Keystore、原生通知和原生分享插件尚未接入。
- 八术算法有自动测试和黄金样本，但仍需要按经典、流派和边界案例持续做独立校勘。
- 典籍正文已按需加载，但核心工作台主包仍约 725 KB，领域模块还有进一步拆包空间。
- 案例与阅读状态尚未迁移到 IndexedDB，也没有跨设备同步。
- 浏览器回归目前由专项 CDP/实机检查执行，仓库尚未纳入长期 Playwright 测试套件。
