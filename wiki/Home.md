# 玄枢 Wiki

玄枢是本地优先的综合术数工作台。系统把确定性的历法/排盘计算、可追溯的规则与典籍证据、用户自己的案例回标，以及可选的第三方 AI 解释分成独立层次，避免模型参与排盘计算或把生成内容伪装成原典。

## 当前能力

| 领域 | 当前实现 |
|---|---|
| 运行端 | Vite + React Web、Electron 桌面端、Capacitor Android |
| 排盘 | 六爻、梅花易数、小六壬、奇门遁甲、大六壬、金口诀、八字、紫微斗数 |
| 引导 | 事项分类、问句质量检查、playbook 断事路径 |
| 知识库 | 18 部、387 章、14200 段内置语料；CJK BM25；IndexedDB 快照 |
| 引用 | `ruleId`、`segId`、`CitationRef` 与 `charRange` 回链 |
| 万年历 | 月视图、农历、干支、节气、宜忌、冲煞与日详情 |
| 应期复盘 | 六爻/奇门日期化时间线、自动生成待观察项、到期与命中统计 |
| 案例本 | 浏览器本地持久化、每术 99 条、回标统计、JSON/CSV/Markdown 导入导出 |
| AI | 7 个配置项（6 个内置厂商 + 自定义 OpenAI 兼容端点）；AI 只解释结构化盘面 |
| 平台边界 | Electron 使用 `safeStorage`；Web/Android Key 当前只保留在页面内存 |
| 自动检查 | 295 项单元测试、7 个领域包 + Web + Electron 严格类型检查、Web 构建 |
