# 响应式设计

同一套 React 页面运行在浏览器、Electron、手机和平板 WebView 中。响应式修改必须同时保证信息完整、可触控和无横向溢出。

## 当前断点

| 条件 | 行为 |
|---|---|
| 默认/桌面 | 页面最大宽度 860px；出生输入为 5 列加性别控制；盘面按可用宽度自动排布 |
| `max-width: 640px` | 缩小页面留白；出生输入改 2 列；表格式盘面转纵向；九宫格收紧；搜索结果限制为 45vh |
| `max-width: 380px` | 九宫格固定 2 列；主要操作和导出按钮占满一行 |
| `pointer: coarse` | 按钮、输入和选择器最小高度 44px；复选框放大到 20px |

页面外层使用 `env(safe-area-inset-*)`，适配刘海、圆角屏和底部手势区域。所有盘面 cell、引用、`ruleId`、章节元数据和案例文本都必须允许断行。

## 必测视口

| 场景 | 建议视口 |
|---|---|
| 小屏手机竖屏 | 360 × 800 |
| 主流手机竖屏 | 390 × 844 |
| 手机横屏 | 844 × 390 |
| 平板竖屏 | 768 × 1024 |
| 平板横屏/小桌面 | 1024 × 768 |
| 桌面 | 1440 × 900 |

## 验收清单

- 页面 `scrollWidth <= clientWidth`，没有整页横向滚动。
- 顶部模式切换和八种术数按钮可见、可换行、不互相覆盖。
- 出生年/月/日/时/分有可见标签，数字输入不会挤出卡片。
- 奇门九宫、紫微十二宫、表格盘面和长引用不会截断关键文字。
- AI/检索输入在手机上逐行排列，Key 显示开关和操作按钮可触控。
- 案例回标按钮换行后，备注输入仍独占足够宽度。
- 典籍章节按钮、正文和来源元数据不产生横向溢出。
- Android WebView 的顶部和底部内容不进入系统安全区。

## 修改原则

不要按视口宽度连续缩放字号。优先使用 `grid`、`flex-wrap`、`minmax(0, 1fr)`、固定断点和内容断行；领域信息太多时允许纵向增长，不通过隐藏关键盘面字段换取“整齐”。
